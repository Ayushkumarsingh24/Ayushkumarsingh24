## 🚀 Featured Projects

### [YOLOv11 + SAHI for Improved Small Object Detection](https://github.com/Ayushkumarsingh24/YOLOv11-and-SAHI-for-improved-small-object-detection-)
Developed a deep learning pipeline for small object detection using YOLO and SAHI, addressing scale variation in traffic scenes where distant vehicles appear smaller and harder to detect. Improved small-object detection performance **without retraining the base model** — detection count rose from 43 → 59 objects on a dense traffic scene.

`Python` `PyTorch` `YOLOv11` `SAHI` `Roboflow` `Google Colab`

### YOLO11 Architecture Optimization for Small Object Detection — *Ongoing*
3rd-year mini project: modifying the YOLO11 architecture via custom YAML configs, integrating specialized modules tailored for micro-scale features on the **VisDrone dataset**. Training and benchmarking **5 distinct architectural variants** on Kaggle GPUs.

📈 **Boosted small object detection accuracy from 37% → 47% mAP@50** — a 10-point absolute gain over baseline YOLO11.

`Python` `PyTorch` `YOLO11` `VisDrone` `Kaggle GPU`
